# JIT — Citta & Cetasika Laboratory

**เว็บจำลองวิถีจิตและเจตสิก 52 ดวงตามกรอบพระอภิธรรม (V0.1)** — static HTML/CSS/JavaScript ที่เปิดผ่าน GitHub Pages ได้โดยไม่ต้องมี API หรือฐานข้อมูล

## ความสามารถที่ทำงานแล้ว

- ข้อมูลเจตสิกครบ **52** ดวง แยก 7 สัพพจิตตสาธารณะ, 6 ปกิณณกะ, 14 อกุศล, 25 โสภณ พร้อม Pāli และความหมายภาษาไทย
- ทุก `CittaMoment` มี `vector` **52 ช่อง** แบบ boolean และ `active` ตามกฎการประกอบจิต–เจตสิก
- เลือก **6 ทวาร** (ตา หู จมูก ลิ้น กาย ใจ)
- ปัญจทวาร: อติมหันตารมณ์ (17 ขณะ), มหันตารมณ์ (ถึงชวนะ), ปริตตารมณ์ (ถึงโวฏฐัพพนะ), อติปริตตารมณ์ (ภวังค์ไหวเท่านั้น)
- มโนทวาร: วิภูตารมณ์ / อวิภูตารมณ์; แสดงชวนจิต 7 ขณะ และตทาลัมพนะตามกรณี
- กรณีศึกษาชวนจิต 16 แบบ ครอบคลุมกุศล อกุศล อัปปมัญญา วิรตี และเจตสิกเฉพาะกรณีที่เกิดร่วมได้ (เลือกเป็นตัวอย่าง ไม่วินิจฉัยผู้ใช้)
- เลือกดูขณะ, เล่นอัตโนมัติ, หยุด/เดินหน้า/ถอย, กรอง/ค้นหา/ตรวจสอบเจตสิก, เครือข่ายสีตามสถานะ, ส่งออกผลเป็น JSON
- เลือกต่อ **ปัญจทวาร → ภวังค์คั่น → มโนทวาร** เพื่อศึกษาความสืบต่อ; จำนวนภวังค์ในส่วนเชื่อมเป็นภาพสาธิต ไม่ใช่จำนวนตายตัว

## เริ่มใช้งาน

```bash
python -m http.server 8000
# เปิด http://localhost:8000
```

หรือเปิด `https://nustanakritwithai.github.io/Jit/` **หลังจากเปิด GitHub Pages จาก branch `main` / root** ใน GitHub Settings → Pages (GitHub ไม่เปิด Pages อัตโนมัติเพียงแค่สร้างรีโป)

ตรวจสอบแกนแบบจำลอง:

```bash
npm run check
npm test
```

## โครงสร้าง

- `src/data.js` — คลังเจตสิก 52 และตัวเลือกตัวอย่าง
- `src/engine.js` — กฎชุดประกอบ, จิตหนึ่งขณะ, ตัวสร้างวิถี, validators
- `src/app.js` — UI timeline / SVG atlas / การเล่น / export JSON
- `index.html`, `styles.css` — UI แบบ responsive
- `tests/engine.test.js` — unit tests ที่รันใน Node 22

## ขอบเขตเชิงหลักธรรมและวิธีการ

**จิตไม่ใช่ผลบวกของเจตสิก** แต่เกิดร่วมและดับร่วมกับเจตสิกซึ่งทำหน้าที่จำเพาะ; ในแบบจำลองหนึ่งขณะคือหนึ่งจิตตปบาท ประกอบด้วยจิตและเจตสิกตามข้อจำกัดทางสัมปโยค โดยใช้เวกเตอร์ 52 ช่องแทนการมี/ไม่มีเท่านั้น ไม่ใช่ค่าความแรงหรือตำแหน่งบนสมอง ขณะปัจจุบันไม่สืบทอดเจตสิกสะสมไปเพิ่มในขณะถัดไป

ระบบใช้ **representative presets** สำหรับบางชนิดจิต ไม่ได้ครอบคลุมสัมปโยคทั้งหมดของจิต **89/121 ประเภท** และไม่ได้จำลองละเอียดตามบุคคล ภูมิ ฌาน มรรคผล หรือความซับซ้อนทุกกรณีของวิถีจิต กรณี `atiparitta` ไม่มีวิถีจิตเกิดขึ้น ตัวอย่างจิตวิบาก/ภวังค์ใช้ชนิดหนึ่งที่อนุญาตตามกรอบอภิธรรม ไม่ได้ตั้งใจให้เป็นชนิดสากลของทุกบุคคล

ความเร็วที่เลือกเป็น **ความเร็วภาพ ไม่ใช่ระยะเวลาของขณะจิต** แผนภาพเครือข่ายเป็นอุปมาในการแสดงข้อมูล **ไม่ใช่ภาพเซลล์ประสาทหรือการระบุว่าเจตสิกคือเซลล์ประสาท**
