**อัปเดต:** เพิ่มหน้าสำรวจ **รูป 28 ประเภท (18 รูปจริง + 10 รูปไม่เกิดสำเร็จ)**, **สมุฏฐาน 4** (กรรม 18 / จิต 15 / อุตุ 13 / อาหาร 12), และ **รูปกลาป 21 กลุ่ม** (9/6/4/2 ตามสมุฏฐาน) จาก *อภิธัมมัตถสังคหะ* บทที่ 6 พร้อมชุดทดสอบกฎอ้างอิงตำรา

**ใช้งาน:** [เปิดหน้ารูป 28](https://nustanakritwithai.github.io/Jit/#rupa) หรือเลือกเมนูรูป 28 ในเว็บ; กรองชนิดรูป คลิกชื่อเพื่อดูคำอธิบายและที่มา เลือกรูปกลาปเพื่อดูองค์ประกอบ ทดลองฐานรูป–อารมณ์ของปัญจวิญญาณ 10 ประเภท ดาวน์โหลดข้อมูล CSV

## V0.4.2 — ขีดจำกัดการอนุมานจิต (แก้ Issue #1)

## V0.4 — ตรวจแหล่งธรรมและแก้กฎอย่างตรวจสอบได้

> **ขอบเขต:** ปัฏฐาน 24 ชื่อมีข้อมูลอ้างอิงครบ; ระบบตรวจความสัมพันธ์ **18 แบบภายในขอบเขตนามธรรมและขณะจิตที่จำลอง** ส่วน **6 แบบเป็น UNKNOWN** ยังไม่ได้ประเมินเพราะขาดข้อมูล ไม่ใช่ประกาศว่าปัจจัยนั้นไม่เกิด

- อ่านคำนิยามตาม **พระอภิธรรมปิฎก ปัฏฐาน Paccayaniddesa §§1–24** โดยตรง แล้วเสริมจากคู่มือ *อภิธัมมัตถสังคหะ* (ไม่ใช่พระไตรปิฎกเอง) และงานอธิบายของ Nina van Gorkom
- เพิ่มนิสสย อาหาร อินทริย ฌาน อัตถิ และอวิคต ในกรณีที่กำหนดตัวรองรับฝ่ายนามได้อย่างเจาะจง; ฌานปัจจัย **ไม่ใช้กับปัญจวิญญาณสิบดวง**
- อาเสวนปัจจัย: ในตัวอย่างอัปปนาปฐมฌานครั้งแรก **ชวนะเตรียมดวงสุดท้าย → ปฐมฌาน** เป็นความสัมพันธ์ที่ตำรากล่าวไว้ และห้ามโยงหลังฌานไปภวังค์
- แต่ละปัจจัยที่ประเมินได้มีหลักฐานว่าองค์ธรรมใดเป็นปัจจัย พร้อมเลขนิทเทสในไฟล์ JSON และหน้ารายละเอียดที่เปิดอ่านได้
- แยก `applies-in-modeled-scope`, `not-applicable-for-this-citta`, `evaluate-at-incoming-edge`, `unknown-or-out-of-scope` อย่างชัดเจน; การไม่มีข้อมูลไม่ใช่ FALSE
- อ่านตารางอ้างอิงและกรณีทดสอบทั้งหมดที่ [docs/PATTHANA_RULE_AUDIT.md](docs/PATTHANA_RULE_AUDIT.md); รัน `npm run check && npm test` ก่อน deploy

## ตรวจรายจิต 121 ประเภทกับตารางต้นฉบับ (V0.4.1)

- ใช้ตารางอ้างอิงแยกต่างหากจาก engine ซึ่งถอดจาก *A Comprehensive Manual of Abhidhamma* ตาราง 1.1 (หน้า 28), 2.2 (หน้า 92), และ 2.3 (หน้า 101)
- ตรวจเทียบสถานะ **ต้องเกิด / แปรผัน / ไม่เกิด** ครบ **121 × 52 = 6,292 ช่อง** แล้ว ไม่พบความต่างในชุดข้อมูลอ้างอิงที่ตรวจ; ข้อสรุปนี้ใช้เฉพาะตารางสัมปโยค ไม่ใช่ผลตรวจความถูกต้องของ Causal Engine ทั้งระบบ
- เมนู **ตารางสัมปโยค** เลือกดูจิตทีละดวง เลื่อนก่อนหน้า/ถัดไป เห็นเลขและชื่อเจตสิกครบทุกสถานะ พร้อมที่มาและข้อจำกัด
- `docs/CITTA_CETASIKA_SOURCE_AUDIT.md` แสดงรายงานแยกครบ 121 จิตและข้อมูลเลขเจตสิกที่ยกมาจากตาราง
- กรณีอัปปมัญญาในจิตประกอบอุเบกขา: ทำหมายเหตุเรื่องความเห็นต่างตามบทที่ 2 §15 ของคู่มือ ไม่กำหนดกฎที่ไม่มีข้อยุติเป็นข้อเท็จจริงเดียว
- ยังคงแยกชัดว่าการจับคู่ในตำราเป็น **กรอบสัมปโยค** ส่วนการเลือกจิตตามเหตุปัจจัยในชีวิตจริงหรือวิถีพิเศษอื่น ๆ ยังไม่ผ่านการรับรองทุกกรณี

### UX ที่ออกแบบใหม่

- **4 พื้นที่หลักแทนหน้าเดียวที่ยาวมาก:** ทดลองวิถีจิต / สำรวจเจตสิก / ตารางสัมปโยค / เหตุปัจจัย (ส่วนหลักการและแหล่งอ้างอิงแยกเป็นหน้าช่วยอ่าน)
- **ทางลัดบนมือถือ:** ปุ่ม `▶ เริ่มจำลองกรณีนี้` ที่อยู่ใต้การเลือกตัวอย่าง ช่วยเริ่มการเล่นและเลื่อนไปยังขณะจิตได้ทันที
- **เริ่มด้วยกรณีศึกษา 4 แบบ:** เห็นรูปแล้วพิจารณา, ได้ยินแล้วขัดเคือง, เห็นแล้วติดข้อง, น้อมใจด้วยกรุณา — แต่ละปุ่มตั้งค่าฉากเพื่อ *การศึกษาเท่านั้น* ไม่ใช่การวินิจฉัยจิตของผู้ใช้
- **อ่านจิตขณะนี้ก่อน:** แสดงชื่อจิต ปัจจัยประกอบที่เด่นไม่เกิน 8 รายการและลำดับที่กำลังเดิน; ชื่อบาลีและรายละเอียดเชิงเทคนิคยังเปิดได้ด้วย `อ่านข้อมูลขณะจิตแบบละเอียด`
- **การตั้งค่าขั้นสูงซ่อนได้:** ระดับการปรากฏของอารมณ์ มโนทวารต่อเนื่อง ภวังค์คั่น และส่งออก JSON อยู่ในปุ่ม `ตั้งค่าเพิ่มเติม`; กฎเดิมยังทำงานทั้งหมด
- **สำรวจเจตสิก:** เริ่มจากรายการที่เกิดร่วมกับขณะนั้น กดดูความหมายด้านข้าง; เครือข่าย 52 โหนดเปิดเพิ่มได้เมื่อต้องการ
- **ตารางสัมปโยค:** เลือกจิตประเภทเดียวเพื่อดู `required / optional / forbidden` ก่อน แล้วจึงขยายตาราง 89/121 × 52 เพื่อเปรียบเทียบหรือดาวน์โหลด CSV
- **เหตุปัจจัย:** มีคำอธิบายภาษาธรรมดาว่าขณะก่อนและขณะนี้เชื่อมกันอย่างไร โดยไม่อ้างการคำนวณปัฏฐาน 24 ปัจจัยทั้งหมด
- **มือถือ:** มีเมนู 4 พื้นที่ด้านล่าง แตะง่าย ตารางใหญ่เลื่อนแนวนอนเอง และแสดงข้อมูลยาวเมื่อผู้ใช้ร้องขอ
- **ซ่อมปุ่มดาวน์โหลด CSV:** แยกฟังก์ชันสร้างตารางออกมาทดสอบว่ามี 89 หรือ 121 แถวจริงและมีคอลัมน์ครบ 52 เจตสิก
- **Deep links:** `#simulation`, `#atlas`, `#sampayoga`, `#conditionality`, `#sources` ช่วยเปิดหน้าเฉพาะพื้นที่โดยตรง

**V0.3 ยังคงตารางสัมปโยค 89/121 × 52 และข้อห้ามการเกิดร่วมของ V0.2** แต่เพิ่ม engine เลือกจิตจากเงื่อนไขกรณีศึกษาและบันทึกแหล่งกฎทุกขณะ พร้อม UX ซ่อนข้อมูลเชิงลึก

## V0.3 · Causal Engine ที่รองรับแล้วจริง

**แยก 3 ชั้นเสมอ:** (1) กฎลำดับวิถีจาก *อภิธัมมัตถสังคหะ* ซึ่งเป็นคู่มือ/สายอรรถาธิบาย ไม่ใช่พระไตรปิฎกโดยตรง (2) กฎกลุ่มจิต–เจตสิกตามตารางสัมปโยคที่ตรวจสอบได้ (3) เงื่อนไขสมมติที่ผู้ใช้เลือกเพื่อดูผลในกรณีศึกษา ไม่ใช่พยากรณ์จิตของบุคคลจริง

1. **Transition Planner:** สร้างขณะถัดไปตาม state ปัจจุบันและระดับอารมณ์/ทวาร/ความชัดที่ผู้ใช้ระบุ แทนการ hardcode รายการ 17 ขณะไว้ล่วงหน้า โดยจำกัดเฉพาะกรณีศึกษาที่เครื่องรองรับ และบันทึก rule ID, แหล่งอ้างอิง, ประเภทหลักฐาน
2. **Resultant Selector:** เลือกหนึ่งตัวอย่างวิบากสำหรับวิญญาณทางปัญจทวาร สัมปฏิจฉนะ และสันตีรณะจาก `objectQuality` ที่ระบุว่าคืออิฏฐารมณ์/อนิฏฐารมณ์/อติอิฏฐารมณ์ โดยคุณลักษณะอารมณ์เป็น *ข้อมูลตั้งต้นของฉาก* ไม่ได้คำนวณจากกรรมจริง และการเลือกตทาลัมพนะถูกติดป้าย `scenario-assumption` เพราะยังขาดข้อจำกัดภูมิ บุคคล ชวนจิต
3. **Guided Javana (ทดลองสอน):** ผู้ใช้เลือกรูปแบบมนสิการแบบโยนิโส/อโยนิโส และแนวโน้มติดข้อง/ขัดเคือง/สงสัย ระบบเลือกหนึ่งกรณีศึกษาชวนจิตจากชุดตัวอย่างที่ผ่านตารางสัมปโยค และติดป้าย `scenario-assumption` ชัดเจน **ไม่ใช่กฎว่ามนสิการหนึ่งชนิดจะบังคับให้เกิดจิตดวงนี้เสมอ** และไม่มีการสุ่ม
4. **Two vīthi:** เงื่อนไขวิถีแรกและวิถีที่สองกำหนดแยกกันได้ โดยแสดงภวังค์คั่นที่ผู้ใช้เลือก มิใช่อนันตรปัจจัยกระโดดข้ามภวังค์
5. **Special workflow เฉพาะหนึ่งตัวอย่าง:** มโนทวารวิถีอัปปนา **ปฐมรูปฌานครั้งแรก** มีชวนะเตรียม 4 (อินทรีย์ปานกลาง) หรือ 3 (อินทรีย์แก่กล้า) ขณะ ตามด้วยรูปาวจรกุศลปฐมฌาน 1 ขณะ แล้วกลับภวังค์ โดยใช้รหัสจิต 31 และ 55 เป็นกรณีสาธิต ไม่มีระบบประเมินสมาธิจริง และยังไม่ครอบคลุมฌานอื่น วิถีมรรค ผล จุติ หรือปฏิสนธิ
6. **Paṭṭhāna coverage:** มีทะเบียนเหตุปัจจัย 24 ชื่อครบ แต่ **18 รายการมีตัวอย่างความสัมพันธ์บางแบบที่ตรวจได้เท่านั้น** อีก 6 รายการแสดง UNKNOWN พร้อมชื่อ/คำอธิบายเพื่ออ้างอิง ไม่ใช่ตัวคำนวณ; ไม่มี numerical weights หรือการทำนายกรรม
7. **Rule Evidence Audit:** แต่ละขณะใน JSON เก็บ `ruleAudit.selection`, `ruleAudit.transition`, `basis` (commentarial-pattern / scenario-assumption), `source`, `inputs` และมีตัวอ่านคำอธิบายใน UI

### ลองอย่างรวดเร็ว

เปิดหน้า “ทดลองวิถีจิต” → กด **“ลองให้เหตุปัจจัยช่วยเลือกชวนจิต”** → ดูแต่ละขณะกับคำอธิบายใต้ชื่อจิต → เข้า “เหตุปัจจัย” เพื่อดู rule ID และแหล่งอ้างอิงของขณะนั้น หรือเปิด **ตั้งค่าเพิ่มเติม** แล้วเลือก **วิถีอัปปนา · ปฐมฌานครั้งแรก (สาธิต)**

### ขอบเขตที่ยังไม่สำเร็จ (ห้ามอ้างว่า PASS)

## ความสามารถเชิงหลักธรรมจาก V0.2

1. **ตารางสัมปโยค 89 × 52 และ 121 × 52:** จิต 89 ตามแบบย่อและ 121 ตามแบบแจกแจงโลกุตตรฌาน พร้อมแถวข้อมูลทุกรายการ รหัสจิต กลุ่ม เวทนา ประเภทกุศล/อกุศล/วิบาก/กิริยา
2. **สถานะแต่ละช่อง:** `required` (ต้องเกิด), `optional` (อาจเกิดเมื่อมีปัจจัย), `forbidden` (เกิดไม่ได้) แยกจากค่าที่ *เกิดจริงในกรณีตัวอย่าง* (true/false)
3. **ตัวแก้เงื่อนไขแบบเคารพกฎพระอภิธรรม:** มานะเฉพาะโลภมูลจิตที่ไม่ประกอบทิฏฐิ; ถีนะ–มิทธะต้องเกิดร่วมกัน; อิสสา/มัจฉริยะ/กุกกุจจะเกิดทีละดวง; วิรตี 3 และอัปปมัญญา 2 เกิดแยกกันในกรณีโลกียะ; วิรตี 3 เกิดร่วมกันเสมอในโลกุตตรจิต
4. **ตรวจทุกขณะจิตด้วย canonical citta ID 1–121:** แทนตารางตัวอย่างกว้าง ๆ ที่เคยเลือกเจตสิกโดยไม่ผูกกับชนิดจิตเฉพาะ
5. **ระหว่างวิถีจิต:** ลำดับหลังวิถีทางปัญจทวาร → ภวังค์คั่นจำนวนที่เลือก *เพื่อการศึกษา* → มโนทวารวิถีถัดไป โดยเลือกชวนจิตวิถีหลังแยกจากวิถีแรกได้
6. **เหตุปัจจัย:** ลงทะเบียนปัฏฐาน 24 ปัจจัยเพื่ออ้างอิง แต่เครื่องจำลอง **ครอบคลุมเฉพาะความสัมพันธ์บางส่วน** ที่พอระบุจากข้อมูล ได้แก่ อนันตร, สมนันตร, นัตถิ, วิคต, อาเสวน (เฉพาะชวนะที่ติดกัน), และปัจจัยที่เกิดร่วมภายในขณะ เช่น เหตุ, อารัมมณ, สหชาต, อัญญมัญญ, สัมปยุตต, กัมม, วิปาก
7. **ตรวจสอบ:** ตารางแบบเลื่อนได้/ค้นหาได้, ส่งออก CSV ทั้ง 89 หรือ 121 แถว, ตรวจตัวแปรเพิ่มเติม, กลับไปที่แถวจิตจาก Timeline, ส่งออก JSON วิถีและเหตุปัจจัย

## ความหมายสำคัญ

**จิตกับเจตสิกไม่ได้รวมตัวจนกลายเป็นจิต:** จิต 1 ดวงและเจตสิกที่เกิดร่วมเป็นหนึ่ง *จิตตปบาท* เกิดและดับร่วมกัน ตามประเภทจิตที่อาศัยเหตุปัจจัยกำหนด ตัวแปร 52 ช่องคือ schema ของแอป ไม่ใช่ว่ามีเจตสิกครบ 52 ดวงเกิดพร้อมกัน

**ตาราง 89 ประเภทไม่ใช่ 121 แถวที่ตัดทิ้ง 32:** โลกุตตรจิต 8 ประเภทในตาราง 89 เป็นหมวดรวมระดับฌาน 1–5 เมื่อเลือกแบบ 89 แปดแถวท้ายใช้ชุด `required` เป็นจุดตัด และ `optional` เป็นส่วนที่ขึ้นกับการแจกแจงระดับฌาน จึงไม่ควรนำแถวรวมไปสร้างจิตเฉพาะขณะ ต้องเลือกระดับฌานในแบบ 121 ก่อน

**ตัวเลขในตาราง 2.3 ของตำราหมายถึงรายการองค์ธรรมที่เป็นไปได้ในหมวด ไม่ได้แปลว่าดวงที่ `optional` ทุกดวงเกิดพร้อมกัน:** ตัวอย่างมหากุศลจิตที่ 31 มี 33 ดวงที่ต้องเกิดและ 5 ดวงที่อาจเกิด (วิรตี 3, อัปปมัญญา 2) แต่ห้ามเปิดวิรตีหลายดวงหรืออัปปมัญญา 2 พร้อมกัน

## วิธีใช้งาน

เปิด `index.html` จาก GitHub Pages หรือรันเว็บเซิร์ฟเวอร์ภายใน (`python -m http.server 8080` แล้วเปิด `http://localhost:8080`). ต้องใช้ HTTP เพราะ JavaScript ใช้ ES modules

- เปิดเมนู “ตารางสัมปโยค” เลือก 89/121, ค้นหา, คลิกชื่อจิตเพื่ออ่านว่าดวงใดบังคับ ดวงใดเกิดได้ ทดลองเปิด optional; ระบบจะปฏิเสธชุดที่เข้ากันไม่ได้
- “เหตุปัจจัย” แสดง incoming/outgoing ของขณะที่เลือก, อาเสวนเฉพาะชวนะต่อชวนะ, ภวังค์คั่นที่จำลอง และสารบบอ้างอิง 24 ปัจจัย

## ข้อจำกัดและการตรวจสอบความถูกต้อง

**ส่วนที่นำมาจากตำรา:** จำนวนชนิดจิต 89/121, เจตสิก 52, กฎว่าเจตสิกใดเกี่ยวข้องกับจิตใด, ข้อจำกัด adjuncts, ลำดับวิถีที่แสดงในกรณีศึกษาปกติ และชื่อปัจจัยที่อธิบายได้จากความสัมพันธ์ตัวอย่าง

**ส่วนที่เป็นสมมติฐาน/การกำหนดฉาก:** ชนิดภวังค์และวิบากที่เลือกเป็นหนึ่งกรณีตัวอย่าง, ชนิดชวนจิตที่ผู้ใช้กำหนดในสองวิถี, ภวังค์คั่น 1–8 ขณะ, อัตลักษณ์อารมณ์ `objectId`, ความเร็วภาพและการลากดูด้วย UI ทั้งหมด **ไม่ใช่ข้อมูลว่าจิตจริงมีค่าตามนี้**

**สิ่งที่ยังไม่ใช่การจำลองครบ:** จิต 121 ทุกประเภทอยู่ใน *ตารางสัมปโยค* แต่ไม่ได้แปลว่าเครื่องจำลองวิถีรองรับวิถีพิเศษทั้งหมด (รองรับตัวอย่างปฐมรูปฌานครั้งแรก แต่ยังไม่ครบมรรค–ผล การตาย/ปฏิสนธิ ฯลฯ). สารบบ 24 ปัจจัยไม่ได้หมายถึงการคำนวณปัจจัยครบทุกอย่าง เช่น วิปปยุตตะ ปุเรชาตะ อธิปติ–อุปนิสสยะหรือการสืบเนื่องของกรรมเฉพาะบุคคล เครื่องจำลองไม่ทำนายผลกรรมและไม่รับรองคุณภาพจิตจริงของผู้ชม
