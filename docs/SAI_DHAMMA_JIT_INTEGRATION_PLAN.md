# สายธรรม × JIT — แผนเชื่อมเกมกับห้องทดลองวิถีจิต

## ระยะ 0: เปิดทางเข้าเรียนรู้จากเกม (พัฒนาแล้ว)

- **เกมต้นทาง:** `/Jit/sai-dhamma/` — เกมสายธรรม (เว็บ HTML5)
- **ห้องทดลอง:** `/Jit/#simulation` — JIT Citta & Cetasika Laboratory
- **ปุ่มในเกม:** ไอคอนหนังสือ **“วิถีจิต”** ที่แถบคำสั่งด้านล่าง
- **บัตรในตำรา:** เมนู **วิธีเล่น → “เรียนรู้วิถีจิตกับ JIT”**
- ทั้งสองใช้ `href="../#simulation"` เปิด `target="_blank"` พร้อม `rel="noopener noreferrer"`. คลิกลิงก์แล้วเรียก `save()` ก่อนเปิดแท็บใหม่ เพื่อไม่ต้องเปลี่ยนหน้าของเกม
- ไม่ส่งข้อมูลตัวละคร `S`, ค่าอินทรีย์/จริต, ศรัทธา, กรรม, เซฟหรือชื่อผู้เล่นไปยัง JIT และไม่เปลี่ยนคีย์เซฟเดิม `saidhamma.v01`
- ไม่มีการเพิ่มหรือลดค่าทางเกมจากการเปิดลิงก์ ไม่มีการเปลี่ยนกฎหรือสมดุลการเล่น
- ไม่ใช้พารามิเตอร์ `fbclid` / `utm_source` ในลิงก์เรียนรู้

**ข้อจำกัด:** ระยะนี้เป็นเพียงลิงก์ออก ไม่ใช่การฝัง Causal Engine หรือการบันทึกผลการเรียนกลับสู่เกม ผู้ใช้กลับไปเล่นในแท็บเดิมได้

## ระยะ 1: สร้างสารบบบทเรียนที่ตรวจคัมภีร์ได้

สร้าง `LESSON_CATALOG` อ้างอิงข้อความแหล่งธรรมอย่างตรวจย้อนกลับได้ โดยแยกพระอภิธรรมปิฎกออกจาก **อภิธัมมัตถสังคหะ** และคำอธิบายภายหลัง

| หัวข้อ | เนื้อหาที่ผู้เล่นเลือกศึกษาด้วยตนเอง | เป้าหมายใน JIT |
|---|---|---|
| 1 | จิต–เจตสิก เกิดร่วมและดับร่วม | ตาราง 121 จิต × 52 เจตสิก |
| 2 | ปัญจทวารวิถีและมโนทวารวิถี | Timeline ในห้องทดลอง |
| 3 | ภวังค์และวาระอารมณ์ที่ไม่ถึงชวนะ | กำลังอารมณ์ 4 ระดับ / 15 แบบ |
| 4 | ชวนะและเจตสิกที่เกิดร่วมได้ | Cetasika Constraint |
| 5 | เหตุปัจจัยเฉพาะที่มีหลักฐาน | Paṭṭhāna / Rūpa–Nāma inspector |

กฎสำคัญ: **ค่าจริต กิเลส ความก้าวหน้าสมาธิ หรืออริยภูมิในเกม ไม่ใช่หลักฐานว่าผู้เล่นหรือตัวละครมีจิต 121 ประเภทใดเกิดจริง** แสดงหัวข้อเรียนรู้โดยไม่ตีความผลในเกมแทนหลักธรรม

## ระยะ 2: เชื่อมบริบทหัวข้อ ไม่ใช่ข้อมูลผู้เล่น

หลังจาก JIT รองรับพารามิเตอร์บทเรียนอย่างเป็นทางการ จึงค่อยให้เกมเปิด URL เช่น `?from=sai-dhamma&lesson=bhavanga#simulation` โดย JIT ตรวจ `lesson` กับ **allowlist** ห้ามใช้รหัสจิต/เจตสิกจากสถานะเกมมาเลือกผลลัพธ์อัตโนมัติ

เสนอรูปแบบ:
```json
{
  "lessonId": "bhavanga",
  "source": "sai-dhamma",
  "kind": "educational-navigation",
  "assumptions": [],
  "playerState": null
}
```

ต้องยังไม่ถือว่าการคลิกจากเหตุการณ์ในเกมพิสูจน์ความสัมพันธ์กรรม–วิบาก หรือยืนยันมรรค–ผล

## ระยะ 3: ทดลอง Mini Lab ในหน้าเกม

พิจารณาแบบอ่านข้อมูลอย่างเดียว (read-only) ก่อน:
- **วิธีแนะนำ:** แยกคอมโพเนนต์บทเรียนจาก JIT ที่ใช้กฎต้นทางร่วมกัน เพื่อไม่ทำสำเนาตารางหรือกฎที่อาจคลาดเคลื่อน
- **วิธีสำรอง:** เปิด `iframe` เฉพาะโหมด JIT ที่รองรับการฝังอย่างชัดเจน หลังตรวจ CSP, responsive mobile, ประสิทธิภาพ และการกลับมาเล่น
- หากใช้ `postMessage` ต้องตรวจ `origin` และจำกัดชนิดข้อมูลกับทิศทางที่ยอมรับ
- ห้ามฝังค่าในเกมเข้ากับเครื่องทำนายจิตจริง หรือใช้คะแนนเกมแทนเหตุปัจจัย 24

## ระยะ 4: ใส่บทเรียนประกอบเหตุการณ์ในเกม

เมื่อเหตุการณ์ที่เป็น **ตัวอย่างเชิงเรื่องเล่า** เกิดขึ้น ผู้เล่นอาจกด “อ่านหลักธรรมที่เกี่ยวข้อง” เพื่อดูบทเรียนซึ่งผ่านการตรวจคัมภีร์แล้ว

การอ่านบทเรียนให้สะสมได้เพียงความก้าวหน้าด้าน **สารานุกรม/ความรู้ที่อ่าน** ไม่ใช่คะแนนยืนยันการเข้าฌาน อรหัตผล หรือการละสังโยชน์ ข้อมูล `completedLessonIds` ถ้ามีควรเก็บแยกและไม่ทำให้เกมปัจจุบันเสียสมดุล

## เกณฑ์ทดสอบก่อนถือว่างานผ่าน

- ปุ่มในเกมและบัตรตำราเปิด `/Jit/#simulation` ในแท็บใหม่ได้จริง ทั้งมือถือและคอมพิวเตอร์
- เกมถูกบันทึกก่อนออก ศรัทธา ตัวละคร รุ่น และความคืบหน้าไม่ถูกรีเซ็ต
- ทดสอบที่ความกว้าง 320 / 390 / 1440 px; แถบด้านล่างไม่บังปุ่มเดิม ไม่ล้นจอ
- คงการทำงานของเมนู “ตำรา”, “เหตุการณ์”, “จัดการสายธรรม” และระบบเล่นต่อ
- ไม่ส่งเซฟหรือข้อมูลผู้เล่นให้ JIT; ไม่มีข้อมูลใน query string ที่ระบุบุคคล
- ตรวจคู่มือ/พระไตรปิฎกก่อนแสดงการเชื่อมโยงจากเหตุการณ์ไปหลักธรรม; **UNKNOWN ≠ PASS**
- ผล CI ยืนยันเพียงการทำงานของโค้ด ต้องแยกจากการรับรองความครบถ้วนด้านหลักธรรม

## ขอบเขตที่ยังไม่ได้ทำ

ยังไม่เพิ่มปุ่มกลับเข้าเกมจาก JIT, ไม่ส่งสถานะผู้เล่นเข้า JIT, ไม่แสดง modal วิถีจิตในเกม, ไม่เพิ่มระบบบทเรียนหรือคะแนนความรู้. ทั้งหมดเป็นแผนขั้นต่อไป ต้องตรวจหลักฐานและ QA ก่อนเผยแพร่
