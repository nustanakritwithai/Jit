# JIT V0.4 — ตรวจหลักฐานปัฏฐานและขอบเขตของกฎ (Rule Evidence Ledger)

สถานะ: **เครื่องสาธิตความสัมพันธ์บางแบบเท่านั้น** ไม่ใช่เครื่องคำนวณปัฏฐานทั้ง 24 ปัจจัยและไม่ใช่เครื่องตรวจจิตจริง

## ลำดับชั้นหลักฐาน

1. **คัมภีร์หลัก (R0):** พระอภิธรรมปิฎก *ปัฏฐาน* (Paṭṭhāna), `Nikkhepavāra`, `Paccayuddesa` รายชื่อ 24 และ `Paccayaniddesa` นิยาม §1–24. [บาลีต้นฉบับ](https://dhammatalks.net/suttacentral/sc2016/sc/pi/patthana1.1.html) · [แปลอังกฤษของ Ayya Agganyani](https://dhammatalks.net/suttacentral/sc2016/sc/en/patthana1.1.html)
2. **การอธิบายใช้งาน (R1):** *A Comprehensive Manual of Abhidhamma*, Ācariya Anuruddha / Bhikkhu Bodhi, Chapter II, IV, VIII; [BPS PDF](https://www.bps.lk/olib/bp/bp304s_Bfodhi_Comprehensive_Manual_of_Abhidhamma.pdf) — เป็น **คู่มือสรุปสำนักอรรถกถา ไม่ใช่พระไตรปิฎกโดยตรง**
3. **งานประกอบ (R2):** Nina van Gorkom, *The Conditionality of Life*, [ฉบับออนไลน์](https://www.abhidhamma.org/study/conditionality-of-life/index.html), โดยเฉพาะ Ch. 11–17. ใช้ตีความข้อยกเว้นและแยกกฎนาม–รูป ไม่แทนที่ข้อความในปัฏฐาน
4. **ข้อกำหนดในแอป (S):** การเลือกชื่อจิตตทาลัมพนะ ตัวอย่างบุคคล อารมณ์ดี/ไม่ดี แรงโยนิโสมนสิการ ภวังคจิตคั่นจำนวนหนึ่ง และการเลือกตัวอย่างวิถีอัปปนา เป็น **สมมติฐานของฉาก** ไม่ใช่ผลที่ตำราบังคับให้เกิด

กติกาการตรวจ: `applies-in-modeled-scope` หมายถึง **ความสัมพันธ์หนึ่งแบบที่ตรวจได้** ไม่ได้หมายความว่าเงื่อนไขนั้นสมบูรณ์ในทุกภูมิหรือทุกวัตถุ ส่วน `unknown-or-out-of-scope` คือ **ไม่มีข้อมูลพอ** ไม่เท่ากับ **ไม่เกิดตามพระอภิธรรม**

## ข้อผิดพลาดที่แก้จาก V0.3

1. **ขาดนิสสย อาหาร อินทริย อัตถิ อวิคต และฌาน** ทั้งที่มีข้อมูลนามธรรมพอตรวจความสัมพันธ์บางแบบได้ → เพิ่ม predicate และผู้เป็นปัจจัย (`proofs`) พร้อมบรรณานุกรมในแต่ละขณะ (ปัฏฐาน §§8,15,16,17,21,24)
2. **อาเสวนจากโคตรภู → ปฐมฌาน:** โค้ดเดิมนับเฉพาะชวนะกามาวจรที่ `cittaId` เดียวกัน จึงพลาดชวนจิตกามาวจรดวงท้ายที่เป็นปัจจัยแก่รูปาวจรกุศลปฐมฌานถัดไป → เพิ่มขอบเขตเฉพาะกรณีปฐมฌานครั้งแรกที่ตำราอธิบาย (ปัฏฐาน §12 + Gorkom Ch.11 pp.72–73)
3. **ฌานปัจจัยไม่ได้ใช้กับปัญจวิญญาณสิบดวง:** แม้จิตเหล่านี้มีเอกัคคตา/เวทนาเป็นเจตสิกสัพพจิตตสาธารณะ แต่ไม่ควรอนุมาน `jhāna-paccaya` จากการมีชื่อปัจจัยนั้นโดยตรง (Gorkom Ch.15 p.96)
4. **แยกผู้เป็นปัจจัยจากเจตสิก:** อาหารปัจจัยฝ่ายนามมี **จิต** ร่วมกับผัสสะและเจตนา; จิตไม่ใช่เจตสิกหมายเลข 53 จึงเพิ่ม field `includesCitta` แทนการยัดลง 52 ตัวแปร
5. **ความถูกต้องของ UNKNOWN:** ปัจจัยที่ต้องทราบรูป/ฐาน/กรรม/ความเป็นใหญ่/การสั่งสมยังไม่ถูกตัดสินจากเวกเตอร์ 52 ดวงอย่างเดียว

## ชุดทดสอบอ้างอิงรายกฎ

`tests/patthana-evidence.test.js` มีกรณีที่ยึดข้อความจากแหล่งอ้างอิง **เป็นค่าคาดหวังอิสระ** (independent fixtures), ตรวจว่า:

- 24 ปัจจัยเรียงตาม `Paccayuddesa` และแต่ละรายการมีตัวอ้างอิง `Paccayaniddesa §n`
- ปัจจัยทางนาม 6 แบบที่เพิ่ม ไม่ถูกเหมารวมเข้ากับปัจจัยนาม–รูป
- ปัญจวิญญาณสิบดวง **ไม่มี** ฌานปัจจัย แม้เอกัคคตาจะเกิดร่วม
- `cittaId=9` โทสมูลจิต ไม่อนุมานโทมนัสเวทนาเป็นองค์ฌานประเภทสุข
- `cittaId=31` มหากุศล กับ `cittaId=55` ปฐมรูปฌาน จำลอง `gotrabhū → appanā` เป็นอาเสวนหนึ่งขณะได้
- อาเสวน *ต้องไม่มี* ใน `appanā → bhavaṅga`, ชวนะสุดท้าย → ตทาลัมพนะ หรือข้ามวิถีที่มีภวังค์คั่น
- สร้างชุดเจตสิกแบบ canonical ทั้ง 121 จิต แล้วตรวจการให้เหตุผลครบทุกแถว
- เมื่อแกล้งใส่/ลบอาเสวนผิด validator ต้อง **FAIL**

## วิถีพิเศษที่ยังไม่รองรับ (UNKNOWN ≠ PASS)

- มรรค–ผล (magga → phala, phala 2/3), การทบทวน (paccavekkhaṇa), ฌานชนิดอื่น, อรูปฌาน, อภิญญา
- วิถีสุดท้าย (มรณาสันนวิถี), จุติ ปฏิสนธิ วิบากจากอดีตกรรม และรายละเอียดรูป–นามที่ครบทุกภูมิ
- ไม่มีการประเมินสมาธิหรือสภาวธรรมจริง ไม่มีการทำนายกรรม หรือแปลงจิตเป็นข้อมูลเซลล์สมอง

**วิธีตรวจซ้ำ:** `npm run check && npm test` หรือดู workflow `JIT checks` บน GitHub Actions หลังส่งขึ้นรีโป
